# Projeto-AnaliseDeSeguran-a-Porto_Da_Barra
Projeto acadêmico de Análise de Segurança da empresa fictícia Porto da Barra, baseado no cenário prático e corporativo criado pelo prof. Alexmário Modesto de Jesus. O repositório simula os desafios, relatórios e rotinas reais de atuação de um Analista de Segurança Júnior.
